# Griffin Security

Griffin Security provides professional security guard services in Edmonton, Calgary, and other areas across Alberta. We offer reliable security solutions for businesses, communities, institutions, construction sites, events, and commercial properties. Our services include on-site security guards, mobile patrols, fire watch security, alarm response, and emergency security support. With licensed guards and a focus on professionalism, reporting, and client safety, Griffin Security helps protect people, property, and daily operations.
